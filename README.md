# 🚀 Featured Projects

### 🔎 TruthGraph
**Multi-Agent Fact Verification & Dynamic Evidence Graph**

A fact-verification framework that retrieves and analyzes evidence to determine whether claims are **supported, contradicted, or unverifiable**.

Built a Dynamic Evidence Graph with **Neo4j** and designed **Consensus-Weighted Confidence Propagation (CWCP)** using source authority, semantic relevance, agent agreement, and graph relationships.

**Stack:** `Python` `LangChain` `Llama 3.1` `Neo4j` `FastAPI` `React` `Docker`

---

### 🧠 JOY — AI-Powered Virtual Therapist

A multimodal emotion analysis system processing **text, voice, and facial expressions** to deliver personalized AI interaction.

Implemented late-fusion emotion recognition using **RoBERTa, Wav2Vec2, and Swin Transformer**.

**Stack:** `Python` `RoBERTa` `Wav2Vec2` `Swin Transformer` `Deep Learning`

---

### 👤 Identif.ai
**Forensic Audio → Facial Attributes → 3D Reconstruction**

An end-to-end forensic pipeline converting eyewitness verbal narration into **2D facial sketches and photorealistic 3D facial models**.

Integrated Whisper ASR, spaCy facial-attribute extraction, Stable Diffusion, ArcFace, RetinaFace and 3DDFA.

**Stack:** `Whisper` `spaCy` `Stable Diffusion` `ArcFace` `RetinaFace` `3DDFA`
